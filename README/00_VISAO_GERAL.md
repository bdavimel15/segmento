# Segmentador de Clientes com IA

Motor para criar grupos dinâmicos de clientes usando linguagem natural, regras visuais e modelos prontos.

## Fluxo principal

Texto do usuário → Zaia/IA → JSON oficial → validação → SQL segura → prévia → execução/auditoria.

## Princípio técnico

O JSON validado é a regra oficial. A SQL é apenas um artefato gerado para prévia, execução e auditoria.
